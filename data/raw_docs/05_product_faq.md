## 1. 产品定位与目标客户

云笔记 Pro 是面向小团队与中小企业的云端笔记、知识库与轻量协作产品，提供：

- 文档编辑与页面树管理  
- 多人实时协作与评论  
- 角色权限与空间管理  
- 链接分享与（高版本）加密分享  
- Open API 与 Webhook（高版本）  
- 可选 SSO（团队版）

目标客户：创业团队、设计/咨询小公司、企业内部项目组知识沉淀。  
非目标：超大型集团知识中台、强合规金融核心交易系统（可引导「私有化咨询」但不承诺交付周期）。

## 3. 试用、开通、升降级

### 3.1 试用

- 专业版、团队版均提供 **14 天** 试用。  
- 试用期内可随时取消，不扣款。  
- 未绑定支付方式：试用结束自动回到免费版，数据保留，但超额功能只读或停用（见 3.3）。  
- 已绑定支付方式：试用结束按所选周期自动扣款；扣款前 3 天发送提醒邮件。

### 3.2 升级与降级

- 升级立即生效，当月按差价折算补齐（演示：按剩余天数差价）。  
- 降级在下一计费周期生效；当前周期已享功能可用至周期结束。  
- 降级导致超出新版本限额（人数/容量）时：超额成员须移出，超额附件进入只读冷冻区 **30 天**，逾期系统可停止下载（演示）。

### 3.3 免费版限制（需主动告知）

- 不支持只读成员角色。  
- 不支持关闭「链接分享」。  
- 不支持加密分享、过期链接、水印。  
- 不开放 API。  
- 历史版本只保留 **7 天**。

## 4. 退款、发票与账单

### 4.1 退款规则

| 类型 | 规则 |
|------|------|
| 年付，购买成功后 7 日内 | 可全额退款（须无大量异常导出行为） |
| 年付，超过 7 日 | 按剩余**整月**折算退款；不足整月不退 |
| 月付 | 不支持退已扣款项；可取消下期续费 |
| 教育/活动折扣单 | 按实付金额计算；已开专票须先红冲 |

退款申请在「费用中心」提交，处理时限 **5–10 个工作日** 退回原支付渠道。

### 4.2 故障补偿

因我方原因导致核心编辑/同步功能连续不可用超过 **24 小时**，用户可申请当月费用 **50%** 补偿券；补偿券不可折现、不可转让，有效期 180 天。补偿不影响法定权利主张。

### 4.3 发票

- 企业：费用中心申请电子发票/专票；抬头须与支付主体一致。  
- 个人：普通电子发票。  
- 时限：到账后 **10 个工作日内** 开具。  
- 信息错误需改票：到票后 30 日内申请，每年限 2 次免费改票（演示）。

## 5. 权限、分享与安全功能

### 5.1 角色定义

| 角色 | 能力摘要 |
|------|----------|
| 所有者 | 转让空间、删除空间、账单、最高权限 |
| 管理员 | 成员管理、权限模板、不可删除空间 |
| 编辑者 | 创建/编辑页面、评论、上传 |
| 只读成员 | 仅阅读与评论（评论可关） |

每个空间有且仅有 **1 名** 所有者；转让须原所有者发起，接收方确认。

### 5.2 分享能力对照

| 能力 | 免费版 | 专业版 | 团队版 |
|------|--------|--------|--------|
| 公开链接 | 有（不可关） | 可关 | 可关 |
| 加密分享 | 无 | 有 | 有 |
| 链接过期 | 无 | 有 | 有 |
| 页面级权限 | 无 | 有 | 有 |
| 水印 | 无 | 无 | 有（可开） |
| SSO（SAML） | 无 | 无 | 有 |
| 审计日志保留 | 7 天 | 90 天 | 365 天 |

### 5.3 安全口径（客服可说）

- 传输 HTTPS；静态数据加密存储（演示口径）。  
- 支持 2FA；团队版可强制全员 2FA。  
- 不承诺「军工级」等未验证表述；禁止承诺「永不丢数据」——应改为「多副本与备份策略，详见信任中心」。

## 6. API、Webhook 与限额

### 6.1 开放范围

- 免费版：不开放 API。  
- 专业版：REST API；Webhook 3 个。  
- 团队版：REST API；Webhook 20 个；更高频配额。

### 6.2 调用限额

| 版本 | API 次数上限 | 说明 |
|------|--------------|------|
| 专业版 | 3,000 次/天 | 按 UTC+8 自然日重置 |
| 团队版 | 50,000 次/天 | 可工单申请临时提升，最多 7 天 |
| 企业版 | 合同约定 | — |

触发限流返回 **HTTP 429**，建议指数退避：初始 1 秒，最多重试 5 次。持续超限可能临时封禁令牌 1 小时。

### 6.3 附件上传大小

| 版本 | 单文件上限 |
|------|------------|
| 免费版 | 20 MB |
| 专业版/团队版 | 200 MB |
| 企业版 | 合同约定（可至 1 GB） |

## 7. 数据导入导出、备份与注销

### 7.1 导出

- 个人笔记：随时导出 Markdown/HTML。  
- 空间级导出（含部分权限元数据）：仅所有者，**每天 1 次**。  
- 导出任务超过 30 分钟未完成可重试；大空间建议分批。

### 7.2 备份

系统侧多副本备份；用户侧仍须自行保留关键导出。客服不得承诺「任意历史时点恢复」——恢复窗口见故障等级与后台策略（二线处理）。

### 7.3 账号注销

- 提交后进入 **15 天冷静期**，可撤回。  
- 期满删除且不可恢复；冷静期内空间只读。  
- 若为企业所有者，须先转让所有者或删除空间成员后方可注销。

## 9. 常见问题快答（一线脚本）

**Q1：一个人能否买团队版？**  
可以，但按团队版计价；长期单人更建议专业版。

**Q2：免费版能否加密分享？**  
不能。加密分享、过期链接为专业版及以上功能。

**Q3：是否支持私有化部署？**  
标准 SaaS 不提供私有化；企业版可评估专有云/混合方案，转商务与解决方案，不承诺交付日期。

**Q4：能否开发票给个人又写公司报销？**  
抬头须与支付账户主体一致；企业支付开企业票，个人支付开个人票。

**Q5：API 超限怎么办？**  
短期可降频重试；团队版可工单申请不超过 7 天的临时额度；长期超限引导升级企业版。

**Q6：误删页面能否恢复？**  
专业版回收站保留 30 天；免费版 7 天。超期不可恢复，勿承诺后台一定能捞。

**Q7：是否可以只要存储不要席位？**  
不可以。容量与席位绑定版本，不单卖存储包（企业版合同另议除外）。

**Q8：竞品迁移是否收费？**  
自助导入免费；人工迁移属增值服务，转成功经理评估。

## 10. 禁止口径与升级规则

### 10.1 禁止口头承诺

- 未在官网/本文出现的折扣、延长试用、永久免费席位。  
- 「数据绝对不会丢」「100% 合规过某某认证」（除非证书页面已公示）。  
- 替用户保证「一定能退全款」而忽略超期规则。

### 10.2 必须升级二线的情况

- 涉及数据恢复、疑似安全漏洞、大客户合同条款解释、疑似欺诈支付。  
- 口径冲突或活动规则不清。  
- 用户威胁媒体曝光或诉讼：记录诉求，转升级通道，不争辩刺激。

升级时工单标注「口径待确认」或「安全可疑」，禁止在未确认前再次向用户承诺。
